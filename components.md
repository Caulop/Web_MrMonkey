# components

- **Botón (.btn):** naranja, borde rasgado por clip-path, condensada 20px. Hover: sube 3px, rota -1°, flecha +6px. Variante `.dark`.
- **Header:** fijo, 10px de padding (4px al hacer scroll), logo 62→48px, enlace activo según sección.
- **Franja (.strip):** 4 ítems icono + texto, damero al borde derecho.
- **Tarjeta de burger (.pcard):** foto 3:2, nombre, descripción, precio, botón agregar circular. Hover: sube 6px, foto x1.05.
- **Carrusel:** scroll-snap horizontal, flechas, teclado ←/→.
- **Panel historia:** foto + bloque naranja con mascota.
- **Newsletter:** input + botón; mensaje de éxito con `aria-live`.
- **Toast de carrito:** confirma "X agregada" durante 1.8s.
